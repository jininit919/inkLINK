CHYBÍ DOPLNIT:

    KALENDÁŘ-FEED (.ICS)

    Přihlas si InkLink rezervace do Google Calendar / Apple Calendar / Outlooku. Po každé nové rezervaci se zobrazí automaticky — feed se synchronizuje cca každých 15 minutes (závisí na klientovi).

    ⚠ Pokud token regeneruješ, starý URL přestane fungovat (všechny aplikace co subscribují se musí znovu přidat).

    JAK SE PŘIHLÁSIT

    Google Calendar: Settings → Add calendar → From URL → vlož URL → Add

    Apple Calendar (Mac): File → New Calendar Subscription → vlož URL → Subscribe

    Apple Calendar (iPhone): Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar → vlož URL

    Outlook: Add calendar → Subscribe from web → vlož URL

    CO BUDEŠ V KALENDÁŘI VIDĚT

    • Potvrzené rezervace (klient + studio + popis)
    • Pending payment (jako TENTATIVE — nepřekáží jiným meetingům)
    • Available slots v kalendáři (TRANSPARENT — počítají se jako available)
    • Storno-vané rezervace se z feedu zmizí automaticky

    Feed je token-protected — kdokoliv s URL vidí tvůj kalendář (read-only). Drž URL stejně tajný jako heslo.
